GOVERNMENT EMBLEM FOR THE PDF REPORT
====================================

Save the Tamil Nadu state emblem in this folder as:

    gov-emblem.png

Recommended: a square PNG, 256x256 or larger, transparent or white background.

It is then centred in the header of every downloaded report automatically.
No code change and no rebuild of the server is needed - the file is read at
the moment a report is produced.

Until the file is present the report draws a neutral placeholder mark, because
an approximation of a state emblem is not something that should be invented.
